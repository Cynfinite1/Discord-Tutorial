3.1 What a Server Is

A server is a private space for one group, class, or club. Only people who are invited can join it.

What is inside a server

Every server contains the same basic parts:

  • Members: the people who joined the server
  • Channels: separate areas for each topic, such as #announcements or #files-and-drafts
  • Owner and moderators: the people who set up the channels and manage the server, such as a group leader or club officer

One account, many servers

You only need one Discord account, even if you join servers for several classes and clubs. Each server you join appears as a round icon in the column on the far left of the Discord window. Click an icon to switch to that server.

NoteLeaving a server does not delete your account. You can rejoin later if someone sends you a new invite link.
